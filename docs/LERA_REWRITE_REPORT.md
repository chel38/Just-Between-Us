# Lera Rewrite Report

## Old → new

| Старый участок | Проблема | Новое решение |
|---|---|---|
| Calm opening | Игрок спрашивал, почему Лера написала первой. | Игрок знает, что Надя передала контакт; Лера только ждала, решится ли он написать. |
| Midnight check | Галерея называлась полноценной встречей. | Игрок говорит «после той галереи», а Лера позже подтверждает, что они не познакомились. |
| Boundary → photo | «Переоделась» почти сразу превращалось в кнопку фото. | Сначала фиксируется право на «нет», затем игрок явно отказывается от доказательств; фото — инициатива Леры. |
| First photo | Пижамная рубашка не выполняла обязательную relationship-функцию. | Новый закрытый непрозрачный двухчастный образ; стабильный asset ID, age 24, localized alt, promo ban. |
| Gallery photo | Платье было доступно только в узкой ветке. | Все продолжающиеся non-bad пути проходят через улику перед reveal. |
| Nadya reveal | Надя давала Лере контакт игрока, а Лера «решала написать сама». | Единственный канон: Лера попросила Надю передать игроку контакт Леры; первым написал игрок. |
| Blacklist | Блок мог следовать слишком быстро. | Лера формулирует границу, предупреждает о последствиях и блокирует только после повторного давления. |
| Start consequences | Пять стартов быстро теряли индивидуальность. | Пять разных ответов, tone flags и условные callbacks в midnight/reveal. |
| Secret ending | Достаточно было двух общих flags. | Требуются точная деталь, честность, уважение, отсутствие лжи и отсутствие давления. |

## Transition audit

Каждый edge проверяется автоматическим audit на существующий node и неубывающее время. Все сцены имеют `sceneContext`; игрок остаётся дома, Лера — у себя. Ни один чат не продолжается после физической встречи: good-date только назначает встречу на следующий день.

## Route QA

Автоматически проигрываются семь полных маршрутов:

1. уважительный → `lera_good_open`;
2. флиртующий с добровольным фото → `lera_good_date`;
3. осторожный → `lera_neutral_morning`;
4. прямой/ироничный → `lera_neutral_distance`;
5. конфликтный → `lera_bad_cold`;
6. повторно давящий → `lera_bad_blocked`;
7. точная память + честность + границы → `lera_secret_known`.

Отдельный тест программно проходит `START → lera_photo_scene` и подтверждает trust, attraction, respect, отсутствие `lera_pushed_for_photo`, реальный asset и RU/EN transcript resolution.
