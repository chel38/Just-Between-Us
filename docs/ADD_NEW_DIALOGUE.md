# Как добавить нового персонажа

## Шаг 1. Скопируйте шаблон

Скопируйте `src/content/dialogues/_template` в папку с латинским ID, например `src/content/dialogues/alice`.

## Шаг 2. Заполните персонажа

В `character.ts` задайте:

- уникальный латинский `id`;
- имя и явно совершеннолетний возраст;
- роль, статус, акцентный цвет;
- пути к двум WebP-аватарам;
- `writingProfile`.

## Шаг 3. Добавьте ассеты

Создайте:

```text
public/assets/characters/alice/avatar.webp
public/assets/characters/alice/avatar-large.webp
```

Рекомендуемые размеры: 160×160 и 640×640. Не используйте пробелы, кириллицу и внешние URL.

## Шаг 4. Спроектируйте граф

Создайте `localization/ru.ts`. Стартовый узел должен иметь пустой `messages` и ровно пять вариантов, ведущих в разные `next`. Каждый финальный узел получает `endingId`.

## Шаг 5. Локализуйте

Создайте `localization/en.ts` с теми же node/message/choice IDs. Меняются только тексты. Никогда не меняйте ID между языками.

## Шаг 6. Опишите концовки

Добавьте минимум хорошие, нейтральные и плохие исходы. Финал должен зависеть от накопленных параметров и флагов, а не от одной последней кнопки.

## Шаг 7. Зарегистрируйте историю

Добавьте фабрику диалога в `src/content/dialogues/index.ts`. Движок, сохранения, Yandex SDK и DialoguePage менять не нужно.

## Шаг 8. Проверьте

```bash
npm run validate:dialogues
npm test
```

Добавьте в тест по одному реальному маршруту до каждой концовки. Ошибка должна быть исправлена в контенте, а не скрыта в валидаторе.
