# Локализация

Поддерживаются `ru` и `en`.

- UI: `src/content/locales/index.ts`;
- история RU: `camila/localization/ru.ts`;
- история EN: `camila/localization/en.ts`;
- имя, роль и концовки: `camila/character.ts`.

В режиме `auto` приоритет имеет `ysdk.environment.i18n.lang`, затем язык браузера. Все неподдерживаемые языки получают английский.

Правило сохранений: ID персонажей, узлов, сообщений, выборов, флагов и концовок никогда не переводятся. Поэтому язык можно переключить во время прохождения; сохранённая история остаётся в исходном языке, новые сообщения приходят на выбранном.
