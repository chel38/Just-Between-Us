# Dialogue template

Copy this directory, replace `replace_me`, create `localization/ru.ts` and `localization/en.ts`, add WebP avatars, endings and a registry entry. Then run `npm run validate:dialogues`.

Скопируйте папку, замените `replace_me`, создайте обе локализации, добавьте WebP-аватары, концовки и регистрацию. Затем запустите валидатор.
